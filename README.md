# 基于 STM32 的智能电子秤

基于 STM32F103C8T6 的计价电子秤：HX711 采集称重传感器信号，4×4 矩阵键盘设置单价、去皮，0.96 寸 OLED 实时显示重量、单价、总价，并附带 DHT11 温湿度显示。

> 课程设计 / 嵌入式练手项目，标准外设库（SPL）开发，Keil MDK 工程。

---

## 一、功能概览

| 功能        | 说明                                                                  |
| ----------- | --------------------------------------------------------------------- |
| 实时称重    | HX711 24 位 ADC 采集，每 100 ms 更新一次，显示精度 0.1 g              |
| 计价        | 总价 = 重量(kg) × 单价(元/kg)，实时刷新                              |
| 单价设置    | 数字键快速定价、自定义 4 位单价、3 组预设单价（默认 10 / 20 / 30 元） |
| 去皮 / 置零 | 连续采样 20 次取平均作为新零点                                        |
| 温湿度显示  | DHT11 每 2 s 采集一次，校验失败时显示 `--` 并点亮 LED               |
| 开机自校准  | 上电蜂鸣提示，显示 `Calibrating...`，采 20 个零点样本               |
| 非阻塞采样  | 主循环 10 ms 轮询，HX711 采用状态机逐位读取，不占用 CPU 等待          |

## 四、软件设计

### 4.1 任务划分

| 周期 / 方式         | 内容                                   | 实现                |
| ------------------- | -------------------------------------- | ------------------- |
| 100 ms（TIM2 中断） | 置位 HX711 采样请求                    | `TIM2_IRQHandler` |
| 2 s（TIM3 中断）    | 置位 DHT11 采集请求                    | `TIM3_IRQHandler` |
| 10 ms（主循环）     | 称重状态机、DHT11 轮询、按键扫描、刷屏 | `main()`          |

两个定时器中断只置标志位，具体读值放在主循环里做，避免在中断中长时间占用。

### 4.2 HX711 非阻塞读取

`ReadHX711InMain()` 用 4 个状态把一次 24 位转换拆到多次主循环里执行：

1. 定时器置位后进入等待
2. 等待 DOUT 拉低（转换完成）
3. 逐位读出 24 位数据（每位 SCK 一个 1 μs 脉冲）
4. 补第 25 个脉冲，选择下一次通道 A、增益 128，做符号扩展后交给换算

优点：主循环不会被 24 个时钟周期卡住，按键和刷屏不受影响。

### 4.3 重量换算与校准

```c
Weight = (float)(raw_ad_value - HX711_Offset) / 200.43;   // 单位：g
Total  = (Weight / 1000.0f) * Price;                       // 单价：元/kg
```

- `200.43` 是本套传感器实测的标定系数（counts/g），换传感器需重新标定
- `HX711_Offset` 在开机时由 20 次采样平均得到；按去皮键会重新采样 20 次
- 重量为负时钳制为 0

### 4.4 DHT11 读取

`DHT11_TriggerRead()` 发起起始信号，`DHT11_ReadDataNonBlocking()` 完成 40 位读取并做校验和校验。每一段等待都带超时上限，失败即退出，不会死等；连续失败 3 次后标记数据无效，界面显示 `T:--C H:--%` 并点亮 LED。

### 4.5 计价与单价编辑

- 数字键 1–9 直接设为对应整数单价，0 设为 0 元
- 按 `CLEAR` 进入单价编辑，最多输入 4 位数字，上限 99.99
- 编辑状态下按 `PRICE1/2/3` 把输入值写入对应预设位并生效
- 非编辑状态下按 `PRICE1/2/3` 直接调用预设单价

### 4.6 显示布局

```
┌────────────────┐
│ W: 123.4g      │  第 1 行：重量
│ T:25C H:60%    │  第 2 行：温度 / 湿度（失败显示 --）
│ P: 12.5Y       │  第 3 行：单价（编辑时显示输入缓冲）
│ T:  1.5Y       │  第 4 行：总价
└────────────────┘
```

## 七、编译与运行

1. Keil MDK 5 打开 `Project.uvprojx`
2. 选择 STM32F103C8 器件，编译（F7）
3. ST-Link / J-Link 下载（F8）
4. 上电后等待 `Calibrating...` 结束（约 1–2 s），空载时显示应接近 `0.0g`
5. 换上实际称重传感器后，按 `200.43` 的算法重新标定系数

## 八、已知问题与可改进项

| # | 问题                                                                              | 建议                             |
| - | --------------------------------------------------------------------------------- | -------------------------------- |
| 1 | 湿度显示用了 `humidity_int - 100`，DHT11 原始值本身就是 0–100%，会导致湿度异常 | 改为直接显示 `humidity_int`    |
| 2 | `HX711_Read()` 中 `while(DOUT_READ());` 无超时，传感器未接会卡死              | 增加超时计数并返回错误           |
| 3 | 去皮与开机校准为阻塞式，约 1–2 s 内按键无响应                                    | 改成状态机分段采样               |
| 4 | 单价上限 99.99，但显示格式 `%4.1f` 只有一位小数                                 | 统一为两位小数显示               |
| 5 | 标定系数写死在代码里                                                              | 增加按键标定流程，或存入 Flash   |
| 6 | 无超载 / 欠载提示                                                                 | 增加阈值判断与蜂鸣提示           |
| 7 | `myusart` 未接入业务                                                            | 可加串口上报，做上位机或小票打印 |
